KINETIC-B2B

■ 형태: B2B Enterprise SaaS (물류 전사 자원 관리 & 자율 의사결정 플랫폼)

■ 정의 (Definition)

비정형 발주서 자동 전표화 및 보안 SQL 파싱 기반 대륙 횡단 화물 물류 관제 시스템

■ 주요 기능 (Key Features)

  • • 비정형 발주서 정규화: 거래처 이메일 발주 텍스트를 상용 ERP 인보이스 규격으로 자동 변환
  • • 보안 Text-to-SQL 파싱: SQLGlot AST 파서 기반으로 DDL/DML 조작을 차단해 안전한 분석 쿼리 컴파일
  • • 실시간 화물 토폴로지 관제: 물류 거점 및 운송 차량 텔레메트리를 시각화하여 바이어 전용 트래킹 제공
  • • 자율 결재 라우팅: LangGraph 상태 머신으로 사내 규정을 검증하고 메신저 승인 웹훅과 연동한 품의 자동화

■ 기술 스택 (Tech Stack)

Python FastAPI LangGraph LLM Agent SQLGlot Pydantic v2 PostgreSQL Docker

[PROJECT 04]

Neighbor-On (이웃ON)

■ 형태: B2G Public Welfare SaaS (독거노인 고독사 예방 & 돌봄 다이어리 플랫폼)

■ 정의 (Definition)

자연어 일상 대화 분석 기반 독거노인 안부 다이어리 자동 생성 및 위험도 관제 시스템

■ 주요 기능 (Key Features)

  • • 말벗 통화 다이어리화: AI 음성 대화 로그를 보호자용 감성 일기 및 일상 요약으로 자동 재구성
  • • 라이프로그 엔터티 추출: 비정형 발화에서 식사 횟수, 외출 여부, 수면 상태 등 5대 바이오마커 추출
  • • 고립·우울 위험도 스코어링: 최근 30일 발화 기저선 대비 어휘 다양성 및 부정 감정 빈도 추적으로 고위험 가구 선별

■ 기술 스택 (Tech Stack)

Python FastAPI RAG LangChain Pydantic v2 KoBERT / Sentiment Analysis Tailwind CSS
[PROJECT 05]

VOX-MEDIK (시니어 케어 다이어리)

■ 형태: B2G / B2B Healthcare Mobile PWA (독일 DiGA 인증 원격 요양 & 임상 텔레메트리 웹앱)

■ 정의 (Definition)

독거 어르신 음성 통화 분석 기반 안부 다이어리 생성 및 독일 법정 요양등급·의사 소견서 자동 발행 플랫폼

■ 주요 기능 (Key Features)

  • • 음성 바이오마커 다이어리화: 어르신 일상 대화 녹취에서 식사, 복약, 관절 통증 지표를 자동 추출해 요약 일기 생성
  • • 환자 마스터 데이터 CRUD: 인적사항, 질환, 장기요양등급(Pflegegrad 1~5), 비상연락처 등록·수정 및 실시간 동기화
  • • SGB XI 요양등급 실시간 계산: 독일 장기요양보험 6대 영역 가중치 기반 등급 판정 및 지원금(Pflegegeld) 즉시 산출
  • • 공식 의사 소견서(Arztbrief) PDF 조판: 독일 공공의료(BfArM DiGA) 표준 서식을 브라우저 격리 렌더러로 원클릭 발행
  • • 128가구 Triage & 방문 동선 관제: 위험군 자동 선별, 방문간호사 순회 경로(Tourenplan) 확인 및 현장 체크인 지원

■ 기술 스택 (Tech Stack)

Python FastAPI Whisper (STT) Pydantic v2 Web Audio API HL7 FHIR R4 Responsive PWA Tailwind CSS
